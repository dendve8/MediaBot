# Mega Mass Downloader Tools V1 🚀

### 💻 A Multi-Purpose Downloader Toolset for Instagram and YouTube

- 📥 **Instagram Downloader**: Automatically download content from Instagram.
- 🎬 **YouTube Downloader**: Automatically download videos from YouTube.
- 🗜️ **Folder Zipper**: Easily compress downloaded files for storage or sharing.

Mega Mass Downloader Tools is designed to automate mass downloading from Instagram and YouTube with a simple menu-based interface. It includes a zipping feature to compress the results for easy archival.

### 📂 Features

1. **Instagram Downloader**: Download content from Instagram by running an external script (`instagram.py`) located in the `lib` folder.
2. **YouTube Downloader**: Download videos from YouTube using an external script (`youtube.py`) in the `lib` folder.
3. **Zip Folder Result**: Compress the downloaded content from Instagram or YouTube into a `.zip` file for easy management.
4. **Easy-to-Use Menu**: The tool provides a command-line interface where you can choose options to download or zip content.
